# 5. Quick Sort: First Partition

Input: `[8, 3, 5, 4, 7, 6, 1, 2]`

Pivot = `2` (last element).

Using the Lomuto partition scheme:
- Compare each element with pivot 2.
- No element is smaller than 2.
- Swap pivot 2 with the first element, 8.

### Array after partition:
`[2, 3, 5, 4, 7, 6, 1, 8]`

`Pivot final index = 0`

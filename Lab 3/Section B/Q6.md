# 6. Radix Sort

Input: `[170, 45, 75, 90, 802, 24, 2, 66]`

Radix Sort processes digits from right to left using stable sorting.

Pass 1: Ones digit
Number	    Ones digit
170	            0
45	            5
75	            5
90	            0
802	            2
24	            4
2	            2
66	            6

Result: `[170, 90, 802, 2, 24, 45, 75, 66]`

Pass 2: Tens digit
Result: `[802, 2, 24, 45, 66, 170, 75, 90]`
